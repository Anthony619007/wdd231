# 🌳 The Urban Canopy Project

A dynamic, three-page information site dedicated to exploring and promoting the vital role of trees in urban environments.

## Pages

### 1. Canopy Mapper (index.html)
- Interactive Leaflet map with neighborhood markers
- Click markers to update statistics (temperature, AQI, tree count)
- JSON data for neighborhood stats

### 2. Tree Library (library.html)
- Filterable gallery of tree species (native, ornamental, shade)
- "Learn More" links to Wikipedia (Remote API integration)
- CO₂ benefit calculator with dynamic results

### 3. Green Team (community.html)
- Upcoming events calendar (JSON data)
- "Report a Tree" feature with Geolocation API
- Form submission with location tracking

## Technologies Used
- HTML5, CSS3, JavaScript
- Leaflet.js (map API)
- Browser Geolocation API
- JSON for data storage
- Remote API integration (Wikipedia)

## Setup
1. Open any HTML file in a modern browser
2. No server required (all assets loaded via CDN)

## Features
- Responsive design for all devices
- Smooth animations and transitions
